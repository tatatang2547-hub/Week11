# Python RegEx Explorer (GUI)

แอปพลิเคชัน GUI สำหรับทดสอบและเรียนรู้การใช้งาน `re` module ในภาษา Python ครอบคลุมการทำงานทั้ง 10 ฟังก์ชันหลัก พร้อมระบบจัดการข้อผิดพลาด (Error Handling) และการโหลดไฟล์ข้อความ

## คุณสมบัติเด่น (Features)
* **การจัดการข้อความ**: รองรับการพิมพ์ข้อความโดยตรง หรือโหลดข้อความจากไฟล์ `.txt`
* **การประมวลผล RegEx**: รองรับฟังก์ชันใน `re` module รวม 10 ฟังก์ชัน
* **ปรับเปลี่ยน พารามิเตอร์**:
  * กำหนด Custom Pattern (Regex)
  * กำหนดข้อความทดแทน (Replace Text)
  * รองรับ Flag `IGNORECASE`
* **Error Handling**: มีระบบ `try-except` ดักจับ `re.error` ป้องกันโปรแกรมเด้งดับเมื่อพิมพ์ Pattern ผิด

---

## รายชื่อ 10 ฟังก์ชัน RegEx ที่รองรับ

1. **`re.findall`**: ค้นหาคำทั้งหมดที่ตรงตาม Pattern คืนค่าเป็น List
2. **`re.search`**: ค้นหาจุดแรกที่ตรงเงื่อนไข คืนค่า Match Object
3. **`re.match`**: ตรวจสอบรูปแบบเฉพาะจุดเริ่มต้นของข้อความ
4. **`re.finditer`**: ค้นหาคำทั้งหมด ส่งคืนเป็น Iterator พร้อมบอก Index span
5. **`re.sub`**: ค้นหาและแทนที่ข้อความด้วยคำใหม่
6. **`re.subn`**: แทนที่ข้อความพร้อมส่งคืนจำนวนครั้งที่ถูกเปลี่ยน
7. **`re.split`**: หั่นข้อความออกเป็นส่วนๆ ตาม Pattern ที่กำหนด
8. **`re.compile`**: คอมไพล์ Pattern เป็น Regex Object เพื่อประมวลผลซ้ำ
9. **`re.fullmatch`**: ตรวจสอบว่าข้อความทั้งหมดตรงตาม Pattern 100% หรือไม่
10. **`re.escape`**: ใส่ Escape sequence ให้ตัวอักษรพิเศษอัตโนมัติ
